Sobre Guardián IRTRA

Detectar. Alertar. Proteger.

Guardián IRTRA es un sistema de detección y alerta perimetral automatizada diseñado para apoyar la seguridad en zonas de mantenimiento de acceso restringido. Mediante sensores y componentes electrónicos, el sistema identifica movimiento y activa respuestas de alerta para advertir la presencia de una persona dentro del área supervisada.

01

Detección

El sensor PIR identifica movimiento dentro del área de seguridad establecida.

02

Procesamiento

Arduino recibe la información del sensor y determina el estado correspondiente del sistema.

03

Alerta

Cuando existe detección, el sistema puede activar una alarma sonora y una señal visual para advertir del ingreso.
